# NavItem

Položka ľavého menu; menu má logo hore, skupiny položiek a stav synchronizácie s prepínačom tmavého režimu dole, ako v Cockpite.

- Skupiny CRM: „Obchod“ (Prehľad, Firmy, Kontakty, Odberné miesta, Dealy, Ponuky, Provízie), „Servis“ (Konverzácie, SLA), „Marketing“ (Segmenty, Kampane), „Systém“ (Nastavenia, Import).
- Nadpis skupiny `caption` v `ink-muted`; položka `body` s ikonou 18 px v `ink-muted`; aktívna položka `surface-muted` a váha 600.
- Počítadlo vpravo len pri niečom, čo vyžaduje akciu (konverzácie po SLA), ako StatusPill.
- Šírka menu 264 px, položka `radius-md`, vnútro 9 × 12 px.
